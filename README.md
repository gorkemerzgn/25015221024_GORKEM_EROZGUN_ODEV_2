# Bağımsız Oyun Geliştirme Topluluğu (Indie Game Club)

## Projenin Amacı
Bu proje, BPR201 İnternet Tabanlı Programlama dersi kapsamında geliştirilmiştir. Bağımsız oyun geliştirmeye meraklı üniversite öğrencilerini bir araya getirmek ve etkinlikleri duyurmak amacıyla tasarlanmıştır.

## Kullanılan Teknolojiler
* HTML5 ve CSS3 (Responsive Design, Flexbox, Hover Animasyonları)
* Vanilla JavaScript (Sadece H3 Başlıklarına Göre Anlık Filtreleme)
* Kütüphane, framework veya backend KULLANILMAMIŞTIR.

## Çalıştırma Adımları
1. Proje dosyalarını GitHub Codespaces üzerinde açın.
2. Terminali açarak aşağıdaki komut ile statik yerel sunucuyu başlatın:
   `python3 -m http.server 8000 --bind 0.0.0.0`
3. "Ports" (Bağlantı Noktaları) sekmesinden 8000 portunu bulun ve "Tarayıcıda Aç" seçeneğine tıklayarak siteyi görüntüleyin.
