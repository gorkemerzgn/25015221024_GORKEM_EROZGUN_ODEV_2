# Bağımsız Oyun Geliştirme Topluluğu (Indie Game Club)

## Projenin Amacı
Bu proje, BPR201 İnternet Tabanlı Programlama dersi kapsamında geliştirilmiştir. Bağımsız oyun geliştirmeye meraklı üniversite öğrencilerinin oyun üretim sürecini öğrenmesi, fikirlerini prototiplere dönüştürmesi ve çalışmalarını paylaşması için rehberler ve topluluk bilgileri sunar.

## Hedef Kitle
Oyun geliştirmeye yeni başlayan veya bilgisini ilerletmek isteyen üniversite öğrencileri; özellikle kodlama, pixel art, oyun tasarımı, ses üretimi ve playtest konularında kendi projelerini geliştirmek isteyenler.

## Kullanılan Teknolojiler
- HTML5 ve CSS3 (duyarlı tasarım, Flexbox, hover ve klavye odağı animasyonları)
- Vanilla JavaScript (yalnızca h3 başlıklarına göre anlık arama)
- Harici kütüphane, framework veya backend kullanılmamıştır.

## Çalıştırma Adımları
1. Projeyi yerel bilgisayarınızda veya GitHub Codespaces üzerinde açın.
2. Kök dizinde terminali açıp statik sunucuyu başlatın:
   `python3 -m http.server 8000`
3. Tarayıcıda `http://localhost:8000` adresini açın. Codespaces kullanıyorsanız 8000 portunu "Ports" sekmesinden açın.

## Dosya Yapısı
- `index.html` — ana sayfa
- `etkinlikler.html` — oyun geliştirme rehberleri ve arama
- `hakkinda.html` — topluluk bilgileri
- `style.css` — sayfa stilleri
- `script.js` — rehber araması ve temizleme etkileşimi
- `README.md` — proje açıklaması ve çalıştırma adımları
- `AI_NOTLARI.md` — yapay zekâ prompt ve kullanım notları
- `TEST_NOTLARI.md` — test senaryoları ve sonuçları
- `ekran_görüntüleri/` — proje ekran görüntüleri
